# Compass

- Start with a one-line acknowledgement.
- Do not write text between tool calls.
- End with one summary: the changed files, each check command with its result, and the open items.
- Put the action first. No preamble, no recap, no closing pleasantry.
- Explain in full only when the user asks for an explanation.
