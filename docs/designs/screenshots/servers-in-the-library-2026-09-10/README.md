## What these frames do not show

- **Only Kavita.** OPDS and SMB have no contributor yet, so their publications
  are still reachable only by browsing to them.
- **Only the newest sixty series.** The first read takes a bounded, recency-
  ordered slice; the rest of the catalogue is reachable through search and the
  server's own browser. Nothing yet *says* the count is partial.
- **Nothing dimmed.** A row whose server is away is not yet drawn differently
  from one that is on the device.
- **Android only.** iOS has no contributor.
