# Repo Map

Keep this short. Agents read it before broad search.

Two independent native apps, no shared code — only the written spec under
`docs/openspec/specs/`. See [ADR-0001](../decisions/0001-independent-native-cores.md).
There is no backend, no API, no web app. A task that sounds like one of those is
almost certainly a misread of the request.

## Task routing

| Task type | Read first | Validate with |
| --------- | ---------- | ------------- |
| Reader behaviour, comics | `ReaderFeature/`, `:feature:reader` | `swift test` · `gradlew :feature:reader:test` |
| Reader behaviour, EPUB/PDF | `StoryArcEpub/`, `:feature:epubreader` | `pnpm build:ios` · `gradlew :feature:epubreader:test` |
| Library, shelves, search | `LibraryFeature/`, `:feature:library` | `swift test` · `gradlew :feature:library:test` |
| Settings, About, privacy | `SettingsFeature/`, `:feature:settings` | both have `allWarningsAsErrors` |
| Opening a file, archives | `Formats/`, `:core:format` | `swift test` · `pnpm corpus:check` |
| A server or a share | `Catalogue/` `Kavita/` `Smb/`, `:core:*` mirrors | `scripts/*-server.*` doubles |
| Storage, progress, downloads | `Persistence/`, `:core:persistence` | Room changes need a written migration |
| A rule both apps must share | the pure type in `StoryArcCore` / `:core:model` | mirrored tests, same order |
| Colour, type, spacing | `packages/design-tokens` | `pnpm tokens:check` — never edit generated output |
| Behaviour that is specified | `docs/openspec/specs/<capability>/spec.md` | `pnpm spec:validate` |

## Apps and packages

| Path | Type | Notes |
| ---- | ---- | ----- |
| `apps/ios` | app | SwiftUI. `StoryArcKit` (10 modules) + `StoryArcEpub`, an iOS-only package `swift test` does **not** cover |
| `apps/android` | app | Compose. `:app`, four `:core:*`, four `:feature:*`, plus `:core:designsystem` |
| `apps/desktop-*` | placeholder | Documented, not built. [ADR-0004](../decisions/0004-desktop-strategy.md) |
| `packages/design-tokens` | source | One OKLCH source generated into Swift and Kotlin. [ADR-0007](../decisions/0007-design-token-pipeline.md) |
| `packages/test-fixtures` | source | The shared corpus both apps read. Generated by `scripts/generate.py` |
| `packages/licences` | source | `notices.json` feeds `THIRD_PARTY_NOTICES.md` |
| `third_party/libarchive` | vendored C | One copy, two build systems. RAR only — no 7-Zip, no LZMA |

## Generated or fragile files

| Path | Rule |
| ---- | ---- |
| `packages/design-tokens` output in either app | Generated. Change the token source, run `pnpm tokens:check` |
| `THIRD_PARTY_NOTICES.md` | Generated from `packages/licences/notices.json`; `pnpm notices:check` enforces it |
| `packages/test-fixtures/**` | Generated by `scripts/generate.py`; `pnpm fixtures:check` enforces the digests |
| `third_party/libarchive/**` | Vendored upstream. Never hand-edit — follow `VENDORING.md`; `pnpm libarchive:pin` enforces it |
| `apps/ios/StoryArc.xcodeproj` | Generated by `xcodegen` from `project.yml`. Its `Package.resolved` **is** committed |
| `docs/openspec/specs/**` | The contract. Change behaviour and the spec together, never one alone |

## Dead zones

- `apps/desktop-*` — planning only, no code to change.
- `docs/openspec/changes/*` — merged proposals are archived; an open one describes work that
  may not exist yet. `docs/openspec/specs/` is what is true.
